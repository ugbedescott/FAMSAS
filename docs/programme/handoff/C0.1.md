## 5. New Findings
- **F-003** `[read]`: Missing authentication; raw `x-user-id` header trust; client privilege escalation via `x-user-role-claim: SUPER_ADMINISTRATOR` (Critical).
- **F-004** `[read]`: Unprotected device registration (`/devices/register`) and revocation (`/devices/:deviceId/revoke`) endpoints; symmetric pre-shared keys instead of asymmetric key pairs (Critical).
- **F-005** `[read]`: Audit logging executed outside database transactions; SHA-256 hash chaining absent (High).
- **F-006** `[read]`: 3rd staff scan creates an audit log entry in `gate.service.ts`, conflicting with Locked Decision L11 (Medium).
- **F-007** `[read]`: HOD permitted to access staff gate reports in `report.controller.ts`, conflicting with Decision O4 (Medium).
- **F-008** `[read]`: Hardcoded 60s monotonic clock drift threshold in `clock-integrity.service.ts`, conflicting with Decision O5 (Low).
- **F-009** `[read]`: Missing delta pull in `SyncModule`; only batch push ingestion supported (High).
- **F-010** `[read]`: Missing server-side biometric matching, encryption at rest, and duplicate detection (High).
- **F-011** `[read]`: Over 15 academic and operational endpoints required by desktop `BcamsApi` are absent (High).
- **F-012** `[read]`: Prisma engine dylib system policy error on macOS Darwin blocks integration and e2e test execution (High).
- **F-013** `[read]`: Empty migration folder `prisma/migrations/20260921060000_concurrency_partial_indexes` (Low).
- **F-014** `[read]`: Missing global `ValidationPipe`, CORS, Helmet, and OpenAPI documentation in `main.ts` (High).
