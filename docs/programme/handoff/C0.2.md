## 5. New Findings
- **F-015** `[read]`: As-Built Report claimed 15 test suites and 150 tests; actual code contains exactly 4 test files and 24 tests (`npm test` passes 24/24) (Medium).
- **F-016** `[read]`: `geolocation-service.ts` is absent; geofence check is hardcoded 1000ms `setTimeout` (distance=38m); events carry no coordinates (High).
- **F-017** `[read]`: `syncNow` comments out `api.batchSync` and simulates sync with timer, blindly clearing IndexedDB; backend route is `/sync/batch` (not `/attendance/batch-sync`) (High).
- **F-018** `[read]`: Gate kiosk uses naive `currentHour >= 14` for clock-out; duplicate scans show UI toast; success scans post unconditionally; violates Locked Decision L11 (Medium).
- **F-019** `[read]`: Gate kiosk does not wrap clock events in `useSyncStore.addPendingItem`; scans fail immediately when offline, violating Locked Decision L1 (High).
- **F-020** `[read]`: Report claimed unified 4-tab workspace at `/academic/academia`; actual routes are fragmented across 3 separate pages (Low).
- **F-021** `[read]`: Gate records are restricted exclusively to Super Admin, adhering to Decision O4 but conflicting with PRD and As-Built Report (Low).
- **F-022** `[read]`: Dev personas, form submission, and app startup unconditionally grant Super Admin privileges with zero production or environment gating (Critical).
- **F-023** `[read]`: Electron 33 is EOL; DevTools accessible in packaged build; CSP absent; `will-navigate` unhandled; IPC handlers lack sender and schema validation; fuses unset; ASAR integrity disabled (Critical).
- **F-024** `[read]`: WebSocket service defaults to unencrypted `ws://` with no authentication tokens; simulation code bundled into production (Medium).
- **F-025** `[read]`: `npm audit` reveals 36 vulnerabilities (5 critical in `shell-quote`, `tar`, `tinypool`; 20 high in `electron`, `app-builder-lib`, `braces`, `extract-zip`) (High).
- **F-026** `[read]`: `PendingQueueItem` lacks domain foreign keys (`studentId`, `sessionId`, `matricNumber`, coordinates) and device cryptographic signatures (violating L2, L3) (High).
- **F-027** `[read]`: Plaintext JWT Bearer token stored in browser `localStorage` without encryption at rest (`safeStorage` absent), indefinite lifetime, and no idle timeout (High).
- **F-028** `[read]`: Sensitive routes (`/gate`, `/sessions`, `/attendance`, `/people/students`, `/people/lecturers`, `/academic/departments`, `courses`) lack `RoleGuard` wrappers, enabling direct URL navigation bypasses (High).
